# LLaMA Factory guide

基于 LLaMA Factory 的大语言模型微调实践教程。

## 项目简介

本仓库包含 LLaMA Factory 的实践教程和笔记，涵盖从环境配置到中文大模型微调的完整流程。

## 内容结构

- **LLaMA_Factory_sft.md**: LLaMA Factory 监督微调详细指南
- **NLP-Task-to-QA-SFT/**: 传统 NLP 任务转换为问答格式进行大模型微调的示例教程

## 涵盖内容

- LLaMA Factory 安装与配置
- LoRA（低秩适应）训练技术
- 中文大模型微调（Qwen 系列等）
- 数据集准备与格式化
- 训练配置与最佳实践
- 模型评估与部署

## 技术栈

- PyTorch
- Transformers
- LoRA/QLoRA
- 中文大模型（Qwen 等）
